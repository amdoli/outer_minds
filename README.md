# Outer Minds

A lightweight, portable, and resolution-independent graph database engine written in CXX. Designed for visual knowledge management and investigation boards—inspired by the *Outer Wilds* rumor mode—this engine provides direct-manipulation spatial mapping where both nodes and connecting lines carry first-class data.

## Compatibility
I'll try as I can to let it run on every machine like 
* Linux
* Windows
* Mac
* Wasm
* Android.  
However, My main focus will be on linux.
